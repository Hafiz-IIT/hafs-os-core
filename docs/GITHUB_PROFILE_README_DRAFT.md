# Syed Hafiz Ali

**Data Science & AI student building reliable agent systems, EXIM/document intelligence, control/RL research prototypes, and logistics simulations.**

My work sits at the intersection of **AI reliability, evidence-gated autonomy, agent memory/governance, document intelligence, EXIM operations, optimization, and applied systems research**.

I use public repositories as an evidence layer: what is implemented, tested, simulated, proposed, or still future work is kept explicitly separate.

## Featured research and builds

### Evidence-Gated Autonomy
**[EXIM-AI-Evidence-Gated-Autonomy](https://github.com/Hafiz-IIT/EXIM-AI-Evidence-Gated-Autonomy)**  
Synthetic research benchmark asking what evidence an AI system should require before taking a consequential action. Includes controlled failure families, provenance attacks, attestation experiments, preregistered future studies, and a preprint manuscript.

### Safe control / RL research
**[safe-rl-action-gate](https://github.com/Hafiz-IIT/safe-rl-action-gate)**  
Runtime action shielding plus transparent control baselines: scalar LQR, residual control composition, a Koopman-inspired nonlinear lift, Bayesian dynamics uncertainty, and research protocols for hybrid control/RL work.

### EXIM document truth and workflow
**[exim-document-truth-bench](https://github.com/Hafiz-IIT/exim-document-truth-bench)** · **[exim-copilot-core](https://github.com/Hafiz-IIT/exim-copilot-core)**  
Synthetic cross-document truth checking and a governed workflow core built around missing evidence, discrepancies, verification, and **ACT / ASK / VERIFY / ESCALATE**.

### Multimodal cargo consistency
**[cargo-scan-consistency-lab](https://github.com/Hafiz-IIT/cargo-scan-consistency-lab)**  
Declaration-vs-observation consistency, provenance-aware multimodal evidence fusion, synthetic cargo scenarios, and a working manuscript scaffold for the broader EXIM AI Co-Pilot research direction.

### Persistent-agent memory governance
**[memory-governor](https://github.com/Hafiz-IIT/memory-governor)**  
SQLite-backed memory with provenance, sensitivity, TTL/expiry, invalidation, explicit forgetting, poison screening, and auditability.

### ~haf.s__ OS
**[hafs-os-core](https://github.com/Hafiz-IIT/hafs-os-core)**  
Governance/orchestration core for a modular personal/company AI system: tasks, permissions, risk, evidence requirements, memory, audit, and authority boundaries.

## Current research direction

I am especially interested in systems that must decide **when to act, when to ask, when to verify, and when to escalate**.

Current paper/experiment directions include:
- residual reinforcement learning around linear-control priors;
- Koopman-inspired linear embeddings for nonlinear control;
- Bayesian dynamics uncertainty for safer action authorization;
- hybrid LQR + learned residual control;
- evidence provenance and verifier dependence;
- persistent-memory reliability;
- multilingual reliability evaluation;
- EXIM document/cargo truth consistency.
