# Research Publication Index

This index maps research directions recovered from earlier conversations into publication-ready tracks without claiming publication where none exists.

## Tier A — strongest current evidence

### Evidence-Gated Autonomy
Question: what evidence threshold should an AI agent require before taking an action whose consequence exceeds the uncertainty of its evidence?

Current evidence includes synthetic scenarios, failure families, stochastic verification experiments, OOD stress tests, provenance attacks, a claim ledger and reproducibility materials.

Repository: [EXIM-AI-Evidence-Gated-Autonomy](https://github.com/Hafiz-IIT/EXIM-AI-Evidence-Gated-Autonomy)

### Agent Evidence Probes
Question: can evidence quality be measured separately from answer quality?

### Memory Governance
Question: should retrieval authority depend on provenance, sensitivity and memory age?

### Safe RL Action Gating
Question: can a learned residual controller improve performance while a transparent safety layer retains action authority?

## Publication rule
A paper title, abstract or research question is **not evidence of publication**.

For every future paper preserve: research question, hypothesis, assumptions, implementation, experiment, result, limitation, reproducibility artifact, claim ledger and eventual external review.
