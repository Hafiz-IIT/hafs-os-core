## Research direction

Modern AI systems increasingly move from **answering** to **acting**.

My portfolio explores the control layer between an agent's internal reasoning and an external consequence:

    Observe → Remember → Gather Evidence → Evaluate Risk
                             ↓
                      ACT / ASK / VERIFY / ESCALATE

The same principle appears in autonomous agents, document intelligence, export-import operations, logistics, institutional workflows and safety-oriented control.

## Engineering standard

The repositories are intentionally **evidence-gated**:

**designed ≠ implemented ≠ tested ≠ deployed**

Where something is simulated, synthetic, planned or not physically implemented, the repository says so.

Each research prototype aims to provide:

- executable code
- deterministic tests
- CI
- explicit assumptions
- reproducible examples
- architecture documentation
- limitations and non-claims
- a clear path from experiment to future research
